# Laboratorio de figuras y portadas

> Nota de limpieza (2026-09-17): esta carpeta ya no contiene imágenes ni PDFs
> de prueba. Los binarios se retiraron del repositorio (derechos sin verificar
> en el caso de imágenes generadas por IA, peso innecesario en Git) y se
> conservan solo en el equipo local. Quedan únicamente los informes escritos.

## Contenido

- `cover-analysis-deepseek.md` — análisis visual de portadas de referencia
  comerciales (capturas del propietario y referencias de Open Library) y de
  un candidato generado con Pollinations; las imágenes no se incluyen. Úsalo como
  referencia de estilo, no como validación: no hubo revisión docente.
- `openrouter-comparison/muse-pdf-proof/REVIEW.md` — prueba técnica de
  incrustar una portada generada (Muse) en un PDF real con el exportador de
  la app. La imagen no puede publicarse hasta verificar sus condiciones de
  uso vía OpenRouter/Meta.

## Estado de derechos de las imágenes generadas (bloqueo abierto)

Los ToS de OpenRouter remiten los derechos sobre las salidas a los Model
Terms de cada modelo. Para `meta/muse-image`, ni la ficha del modelo ni los
metadatos públicos del endpoint aportaron condiciones suficientes. Hasta
verificarlas, ninguna imagen generada con Muse se publica ni se redistribuye
en este repositorio.
